How the simulation works

Each directed edge has an independent rate-one exponential weight. By exponential memorylessness, after each minimum is subtracted, the remaining eligible outgoing edges have independent exponential residuals. The minimizing edge is uniform among the original edges leaving the active block. In a complete directed graph every outside vertex receives the same number of these edges, so we can sample the target directly without storing all the weights.

One step selects one outgoing edge. Hitting an earlier block on the current path contracts the whole cycle. The curve follows the first contracted block and every block that later absorbs it. The run stops on its first visit to ∂. An early boundary hit can leave little or no growth.
